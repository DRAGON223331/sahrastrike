# صحراء سترايك 🏜️

لعبة تكتيكية 5 ضد 5 على المتصفح (3D)، طابع صحراوي عربي. أسلحة وخناجر بس — بدون قدرات خاصة.

## التشغيل
```
npm install
npm start        # http://localhost:3000   (غيّر المنفذ بـ PORT=8080)
```
افتح الرابط في Chrome/Edge/Firefox. للعب أونلاين مع ناس: شغّل السيرفر على استضافة (Render/Railway/VPS) وشارك الرابط، أو على شبكتك المحلية بعنوان الجهاز.

## أنماط اللعب
- **تدريب ضد البوتات**: 3 مستويات صعوبة.
- **مباراة سريعة**: صالة عامة بعدّاد 15 ثانية، الأماكن الفاضية بتتملى بوتات، ولاعب جديد يحل محل بوت.
- **غرفة خاصة**: كود من 4 حروف، المضيف يبدأ المباراة.

## القواعد
مهاجمين يزرعوا القنبلة في A أو B، مدافعين يمنعوا/يفكّوها. أول فريق لـ 7 جولات، تبديل الجهات بعد الجولة 6. اقتصاد: مكافآت فوز/خسارة + 200$ لكل قتلة.

## الأسلحة
الخنجر (طعنة خلفية قاتلة) · الصقر (مسدس) · العقرب (SMG) · الكلاش (بندقية) · النسر (قناص) + درع.

## التحكم
WASD حركة · Shift مشي هادي · Space قفز · ضغط يسار إطلاق · يمين تصويب القناص/طعنة قوية · R تعبئة · 1/2/3 تبديل · B شراء · E (مطوّلاً) زرع/فك · Tab نتائج.

## الاختبار
`npm test` — محاكاة مباراة بوتات كاملة على السيرفر.

## الجرافيك
الخامات مولّدة بالكود. لاستبدالها بصور Higgsfield شوف `assets/PROMPTS.md`.

## النشر (GitHub + Vercel)
Vercel بيستضيف الموقع (الملفات الثابتة) بس، لكن **مش بيشغّل سيرفر WebSocket** اللي اللعبة محتاجاه. فالنشر على خطوتين:
1. **السيرفر** (`npm start`) على استضافة بتدعم Node دايم التشغيل + WebSocket: Render أو Railway أو Fly.io (Build: `npm install`، Start: `npm start`). هتاخد رابط زي `https://sahraa.onrender.com`.
2. **الموقع** على Vercel: ارفع المشروع على GitHub، استورده في Vercel (الإعدادات جاهزة في `vercel.json`)، وضيف متغير بيئة `SERVER_URL=wss://sahraa.onrender.com`. أو عدّل `client/config.js` بنفس القيمة.
لو عايز أسهل: انشر كل حاجة على Render لوحده (السيرفر بيقدّم الموقع كمان) وسيب `SERVER_URL` فاضي.
